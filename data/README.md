# Input data

These files are large or third-party, so they are not committed. Put them in this folder.

| File | Where to get it |
| --- | --- |
| Catastro buildings: `A.ES.SDGC.BU.<code>.zip` | Catastro INSPIRE ATOM feed for Las Palmas province: http://www.catastro.hacienda.gob.es/INSPIRE/buildings/35/ES.SDGC.bu.atom_35.xml (pick the Las Palmas de Gran Canaria entry) |
| ISTAC barrio boundaries | ISTAC WMS, layer `Barrios-2018`, requested as GeoJSON |
| ISTAC barrio names | Code list `CL_BARRIOS_ES70_2024` (`codes.csv`) from [datos.canarias.es](https://datos.canarias.es/catalogos/general/dataset/clasificacion-de-barrios-de-principales-municipios-de-canarias-para-el-ano-2024-istac-cl_b-20241) |

OpenStreetMap data (walking network, parks, playgrounds) is downloaded by the script itself.
